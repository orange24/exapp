# exapp-card-agent

อ่านบัตรประชาชนไทยที่เคาน์เตอร์แล้วส่งขึ้น exapp

## มันทำงานยังไง

เฝ้าช่องเสียบบัตรอยู่ตลอด เสียบเมื่อไหร่ก็อ่านแล้วยิงขึ้นเซิร์ฟเวอร์
หน้าซื้อ/ขายที่เปิดค้างอยู่จะเติมข้อมูลให้เอง **ไม่ต้องกดปุ่มอะไรก่อน**

โปรแกรมนี้ไม่เปิดพอร์ตและไม่รับคำสั่งจากใคร เพราะหน้าเว็บ HTTPS เรียก
`http://127.0.0.1` ไม่ได้อยู่แล้ว — Chrome บล็อกตั้งแต่ต้นทาง

## ติดตั้งที่สาขา

1. ผู้ดูแลระบบสร้างเครื่องที่หน้า **ผู้ดูแล → เครื่องอ่านบัตรประชาชน**
   แล้วคัดลอก token (แสดงครั้งเดียว ปิดแล้วดูไม่ได้อีก)

2. ที่เครื่องสาขา เสียบเครื่องอ่าน ACR1581U-CF แล้วรัน:

   ```
   exapp-card-agent -setup -server https://exapp.softernity.com -token crd_xxxxx
   ```

3. รันโปรแกรม:

   ```
   exapp-card-agent
   ```

ไฟสถานะที่มุมหน้าซื้อ/ขายจะเปลี่ยนเป็นเขียวภายในครึ่งนาที

## ไฟสถานะบอกอะไร

| สี | ความหมาย | ทำยังไง |
|---|---|---|
| เขียว | พร้อม | เสียบบัตรได้เลย |
| แดง | เสียบบัตรแล้วอ่านไม่ออก | เช็ดหน้าสัมผัสบัตร ลองใหม่ |
| เทา | ไม่ได้ยินจากเครื่องเกิน 2 นาที | โปรแกรมปิดอยู่ หรือเน็ตมีปัญหา |
| ไม่มีไฟ | เคาน์เตอร์นี้ยังไม่ได้ลงทะเบียนเครื่อง | แจ้งผู้ดูแลระบบ |

## ความปลอดภัย

- token เก็บในไฟล์สิทธิ์ `0600` ที่โฟลเดอร์ตั้งค่าของผู้ใช้
- เซิร์ฟเวอร์เก็บแค่ลายนิ้วมือของ token ไม่เก็บตัวจริง
- เครื่องหาย → ผู้ดูแลกดเพิกถอน เครื่องนั้นส่งข้อมูลไม่ได้อีกทันที
  และ agent จะหยุดทำงานเองเมื่อได้ 401
- ปฏิเสธ `http://` ธรรมดา เพราะ token เดินทางไปกับทุกคำขอ

## ข้อมูลที่ส่งขึ้นไปอยู่นานแค่ไหน

เซิร์ฟเวอร์เก็บไว้ **ไม่เกิน 2 นาที** ผูกกับเคาน์เตอร์เดียว ถ้าไม่มีใครมารับก็ลบทิ้ง
และไม่เขียนลงทะเบียนลูกค้าจนกว่าพนักงานจะกดบันทึกรายการจริง

## สำหรับนักพัฒนา

```
cd agent
go test ./...                              # ตรรกะทั้งหมดที่ไม่ต้องใช้ฮาร์ดแวร์
go build -o exapp-card-agent ./cmd/exapp-card-agent
```

Windows build ด้วย GitHub Actions (`.github/workflows/card-agent.yml`) เพราะ cgo
ข้าม platform ไม่ได้ ติด tag `card-agent-v1.0.0` แล้วไฟล์ `.exe` จะไปอยู่ใน release

**ส่วนที่ทดสอบอัตโนมัติไม่ได้คือ `internal/card/reader.go`** ซึ่งคุยกับฮาร์ดแวร์จริง
ตรรกะการแปลงข้อมูล (TIS-620, พ.ศ. → ค.ศ., หลักตรวจสอบเลขบัตร) แยกไว้ใน `card.go`
และทดสอบครบโดยไม่ต้องมีบัตร
