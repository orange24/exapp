💵 รับซื้อเงินตราต่างประเทศ (Buy)

ลูกค้านำเงินต่างประเทศมาขาย → ร้านจ่าย THB ให้ลูกค้า

กรอกชื่อลูกค้า→ ถ่ายรูป/กรอก Passport→ เลือกสกุลเงิน + จำนวน→ บันทึก & พิมพ์

ข้อมูลลูกค้า & Passport

  • Autocomplete — พิมพ์ชื่อหรือเลข passport → ระบบแนะนำลูกค้าเดิม
  • ถ่ายรูป Passport → Crop เฉพาะส่วน MRZ → OCR อ่านข้อมูลอัตโนมัติ
  • กรอกมือ — ไม่ต้องถ่ายรูปก็กรอก passport no, สัญชาติ, วันหมดอายุได้
  • หลังบันทึกแล้วยังแก้ไขข้อมูลลูกค้าได้ → กด "บันทึกข้อมูลลูกค้า"

Side Panel (ด้านขวา)

  • แสดง Stock, Hold, Available ของ denomination ที่เลือก
  • แสดง Avg Cost, Buy Rate, Sell Rate
  • แสดง Margin (ส่วนต่าง rate กับ cost) + Spread
  • อัปเดตอัตโนมัติเมื่อเปลี่ยน denomination

หลังบันทึก

  • ใบเสร็จ A5 พิมพ์อัตโนมัติ (auto print)
  • รายการแสดง read-only + ปุ่ม "พิมพ์อีกครั้ง"
  • กด "+ สร้างใหม่" เพื่อเริ่มรายการถัดไป
  • สต็อกเพิ่มขึ้นอัตโนมัติ + บันทึก GL Journal

💱 จ่ายขายเงินตราต่างประเทศ (Sell)

ลูกค้านำ THB มาซื้อเงินต่างประเทศ → ร้านจ่ายเงินต่างประเทศให้ลูกค้า

กรอกชื่อลูกค้า→ เลือกสกุลเงิน→ กรอก THB ที่ลูกค้าให้→ ระบบคำนวณจำนวนเงินต่างประเทศ→ บันทึก & พิมพ์

กรณีเงินในบูธไม่พอ

ถ้าจำนวนเงินต่างประเทศที่คำนวณได้มากกว่าที่มีในบูธ → ระบบแสดง modal ปรับจำนวน ให้ขายเท่าที่มี พร้อมคำนวณ THB ใหม่

🏦 ขายเงินตราให้ธนาคาร (Sell to Bank)

ขายเงินตราต่างประเทศให้ธนาคาร — รวมสต็อกจากหลายสาขา, มีระบบ Reserve + ขนส่ง + P&L

Flow การทำงาน

สร้างรายการ→ Reserved→ In Transit→ Delivered→ Completed

สร้างรายการ

  • เลือกธนาคารปลายทาง
  • เลือกสกุลเงิน + ธนบัตร + จำนวน + เรทขาย
  • เลือกแหล่งสต็อกจากแต่ละเคาน์เตอร์/สาขา
  • ระบบแสดง P&L Preview (Revenue - Cost = กำไร/ขาดทุน)
  • กด "สร้างรายการ" → สต็อก Reserve ทันที (hold_amount เพิ่ม)

ยืนยันขายสำเร็จ

  • กด "ยืนยัน" → ตัดสต็อกจริงจากทุกสาขาที่เลือก
  • คำนวณ P&L: Revenue (จำนวน × เรทขาย) - Cost (จำนวน × avg cost)
  • สร้าง GL Journal อัตโนมัติ: Dr เงินฝากธนาคาร, Cr สินค้าคงเหลือ FX + กำไร/ขาดทุน
  • ยกเลิกได้ → สต็อก release กลับทั้งหมด

📋 จองเงินตรา (Booking/Hold)

จองเงินตราไว้ให้ลูกค้า — กันสต็อกทันที (Reserved Stock) ลูกค้ามายืนยัน → ตัดขายจริง

สร้าง Booking→ รอดำเนินการ (กัน stock)→ ยืนยัน → สร้างรายการขายจริง

การกันสต็อก

  • Booking ประเภท "ขาย" → hold_amount เพิ่มทันที
  • Available Stock = Stock - Hold (ป้องกันขายซ้ำ)
  • ตั้งเวลาหมดอายุได้ (1-1,440 นาที)

Auto-Expire

  • ระบบตรวจสอบ booking หมดอายุ ทุกนาที
  • หมดอายุ → status = expired + release stock อัตโนมัติ
  • ยกเลิกได้ → release stock ทันที

❌ ยกเลิกรายการ

ยกเลิกธุรกรรม (Buy/Sell)

Staff กด "ขอยกเลิก"→ ใส่เหตุผล → รอยกเลิก→ Admin กด "อนุมัติยกเลิก"→ ยกเลิกสำเร็จ
  • สต็อกคืนกลับอัตโนมัติ (reverse inventory)
  • GL Journal กลับรายการอัตโนมัติ (reversal entry)
  • รายงานไม่รวมรายการที่ยกเลิก
  • ไม่ลบรายการจริง — เปลี่ยน status เท่านั้น (audit trail)

ยกเลิกยืม/คืน/โอน

กดปุ่ม "ยกเลิก" ในตาราง → ระบบ reverse stock ทั้ง 2 ฝั่ง (ต้นทาง + ปลายทาง) + กลับ GL Journal

📊 ตั้งราคา / อัตราแลกเปลี่ยน

3 วิธีตั้งราคา

วิธีคำอธิบายเหมาะกับ
ตั้งราคาตรง ไปที่เคาน์เตอร์ → กรอก Buy/Sell rate ต่อ denomination ตั้งราคาเฉพาะเคาน์เตอร์
ตั้งค่าคำนวณ (Rate Calc) สร้างกลุ่ม → เลือกเคาน์เตอร์หลัก → ตั้ง adjustment → "คำนวณราคา" กระจายไปสาขา ตั้งราคาหลายสาขาพร้อมกัน
SuperRich อ้างอิง ดึงราคาจาก SuperRich → ตั้ง adjustment → สร้างชุดราคา → อนุมัติ → กระจาย ใช้ราคาตลาดเป็นฐาน

จอแสดงราคา (Rate Board)

หน้าจอสาธารณะ (ไม่ต้อง login) แสดงราคาซื้อ/ขายแบบ real-time — พื้นดำ, ซื้อ = เขียว, ขาย = แดง, auto-refresh ทุก 5 นาที

⚡ SuperRich อัตราอ้างอิง

ดึงราคา SuperRich→ ตั้งค่า Adjustment (+/-)→ เลือกเคาน์เตอร์เป้าหมาย→ สร้างชุดราคา→ รออนุมัติ→ อนุมัติ → กระจายราคา
  • ดึง 42 สกุลเงินจาก SuperRich Thailand API
  • ตั้ง adjustment +/- ต่อ denomination (เช่น SuperRich Buy 32.59 + Adj -0.10 = 32.49)
  • ต้อง Admin/Accounting อนุมัติ ก่อนกระจายไปสาขา
  • ทุกการเปลี่ยนแปลง rate มี Rate Change Log

📦 คลังเงินตรา (Inventory)

ข้อมูลที่ติดตาม

ข้อมูลคำอธิบาย
Stock (Quantity)จำนวนเงินตราทั้งหมดในเคาน์เตอร์
Hold Amountจำนวนที่ถูกจอง (Booking / Bank Sale)
AvailableStock - Hold = จำนวนที่พร้อมขาย
Avg Costต้นทุนเฉลี่ยถ่วงน้ำหนัก (Weighted Average Cost)
Total Cost ValueStock × Avg Cost = มูลค่ารวม

เปิด/ปิดวัน (Open/Close Day)

  • เปิดวัน → บันทึก opening balance จาก stock ปัจจุบัน
  • ปิดวัน → สรุป buy, sell, transfer in/out, closing balance

🔄 ยืม/คืน/โอนสินค้า

ประเภทคำอธิบายผลต่อ Inventory
ยืม (Borrow) ยืมเงินตราจากเคาน์เตอร์อื่น ต้นทาง -stock, ปลายทาง +stock
คืน (Return) คืนเงินตราที่ยืมมา สลับทิศกับยืม
เบิกจ่าย (Disbursement) เบิกจ่ายเงินให้เคาน์เตอร์ (จาก HQ) HQ -stock, สาขา +stock
คืนระหว่างวัน (Intra-day) คืนเงินกลับก่อนปิดวัน สาขา -stock, HQ +stock
ปรับปรุงสต็อก (Adjust) ปรับเพิ่ม/ลด stock + ระบุเหตุผล เพิ่ม/ลดโดยตรง + GL Journal

ทุกรายการสามารถ ยกเลิก ได้ → reverse stock ทั้ง 2 ฝั่ง + กลับ GL Journal

👥 สิทธิ์ผู้ใช้งาน (Roles)

Admin

  • เข้าถึงทุกเมนู + ทุกสาขา
  • ตั้งราคา + กระจายราคา
  • อนุมัติยกเลิก + approve ต่างๆ
  • จัดการ user + สิทธิ์ + สาขา
  • ขายธนาคาร + SuperRich
  • ดูรายงานทุกสาขา

Staff

  • ซื้อ/ขายเงินตราที่เคาน์เตอร์ตัวเอง
  • ดูรายการของตัวเอง
  • ขอยกเลิกรายการ (ต้องรอ admin อนุมัติ)
  • ดู stock + ทำ booking
  • ไม่เห็นเมนู Setting + ค้นหารายการทุกสาขา

Auditor

  • ดูรายงานทุกสาขา (read-only)
  • สรุปยอดบัญชี + Avg Rate
  • ดู stock + movements
  • ไม่สามารถสร้าง/แก้ไขรายการ
  • Export ข้อมูลได้
