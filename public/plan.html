AutoJournalService — Core Logic

class AutoJournalService
{
    public function createFromTransaction(TransactionMaster $txn): JournalEntry
    {
        $mapping = TransactionAccountMapping::where('trns_type', $txn->trns_type)->first();

        $entry = JournalEntry::create([
            'entry_no'    => 'AJ' . now()->format('Ymd') . str_pad(...),
            'entry_date'  => today(),
            'description' => "Auto: {$txn->trns_no}",
            'type'        => 'auto',
            'source_type' => 'transaction',
            'source_id'   => $txn->id,
            'branch_id'   => $txn->counter->branch_id,
        ]);

        $totalThb = $txn->totalThb;
        $costValue = // sum(detail.amount * avg_cost) for each currency line

        // Main entry: Dr/Cr ตาม mapping
        JournalLine::create(['debit' => $totalThb, 'account_id' => $mapping->debit_account_id]);
        JournalLine::create(['credit' => $costValue, 'account_id' => $mapping->credit_account_id]);

        // P&L entry (ถ้ามี gain/loss)
        if ($totalThb > $costValue && $mapping->pl_credit_account_id) {
            JournalLine::create(['credit' => $totalThb - $costValue,
                                 'account_id' => $mapping->pl_credit_account_id]); // FX Gain
        } elseif ($totalThb < $costValue && $mapping->pl_debit_account_id) {
            JournalLine::create(['debit' => $costValue - $totalThb,
                                 'account_id' => $mapping->pl_debit_account_id]); // FX Loss
        }

        return $entry;
    }
}

Implementation

เพิ่ม computed property stockInfo ใน buy-form/sell-form component
Trigger เมื่อ selectedCurrency เปลี่ยน → query CounterStock + CounterRate ของเคาน์เตอร์ปัจจุบัน

// ใน buy-form component class
#[Computed]
public function stockInfo(): ?array
{
    if (!$this->selectedCurrency || !$this->counterId) return null;

    $stock = CounterStock::where('counter_id', $this->counterId)
        ->where('denomination_id', $this->selectedCurrency)->first();
    $rate  = CounterRate::where('counter_id', $this->counterId)
        ->where('denomination_id', $this->selectedCurrency)
        ->whereDate('rate_date', today())->first();

    return [
        'quantity'  => $stock?->quantity ?? 0,
        'hold'      => $stock?->hold_amount ?? 0,
        'available' => $stock?->available ?? 0,
        'avg_cost'  => $stock?->avg_cost ?? 0,
        'buy_rate'  => $rate?->rate_buy ?? 0,
        'sell_rate' => $rate?->rate_sell ?? 0,
    ];
}

4. Phase 2: Booking Enhancement

ปัจจุบัน vs เป้าหมาย

ปัจจุบัน

  • ✅ hold_amount เพิ่มตอน create booking
  • ✅ hold_amount ลดตอน confirm/cancel
  • ❌ ไม่มี auto-expire
  • ❌ confirm ไม่สร้าง transaction จริง
  • ❌ ไม่มี GL journal

เป้าหมาย

  • ✅ Reserved Stock ทันที
  • ✅ Auto-expire → release hold_amount
  • ✅ Confirm → สร้าง Sell transaction จาก reserved
  • ✅ Cancel → release stock + GL reversal
  • ✅ Auto GL: Dr 2300 เงินรับล่วงหน้า / Cr 1400 Inventory

New: Scheduled Auto-Expire Command

// app/Console/Commands/ExpireBookings.php
class ExpireBookings extends Command
{
    protected $signature = 'bookings:expire';

    public function handle()
    {
        $expired = Booking::where('status', 'pending')
            ->where('expires_at', '<', now())->get();

        foreach ($expired as $booking) {
            // Release hold_amount on CounterStock
            CounterStock::where(...)
                ->decrement('hold_amount', $booking->amount);
            $booking->update(['status' => 'expired']);
        }
    }
}

8. Assumptions

  • Weighted Average Cost (WAC) — ยังคงใช้ WAC เป็นวิธีคำนวณต้นทุน (ไม่เปลี่ยนเป็น FIFO/LIFO)
  • Single Currency per Bank Sale — ขายธนาคาร 1 รายการ = 1 สกุลเงิน (ถ้าขายหลายสกุลต้องสร้างหลายรายการ)
  • Bank list จาก config/dropdown — ไม่สร้าง banks table แยก ใช้ dropdown ค่าคงที่ก่อน (เพิ่ม CRUD ทีหลังถ้าจำเป็น)
  • In-Transit ไม่ตัด stock ทันที — stock ถูก reserve (hold_amount) แต่ยังไม่ตัดจริง จนกว่า status=completed
  • P&L คำนวณตอน complete — ใช้ avg_cost ณ วันที่ขาย ไม่ใช่วันที่ reserve
  • Auto Journal ไม่ auto-post — สร้าง journal entry แต่ is_posted=false ต้องให้ accounting review ก่อน post
  • Booking auto-expire — ต้อง run scheduler (Cloud Run ต้อง setup cron job หรือ Cloud Scheduler)
  • ไม่ลบรายการจริง — ใช้ status cancel/void เท่านั้น ไม่ hard delete
  • Side Panel — แสดงเฉพาะ denomination ที่เลือก ไม่แสดงทุก denomination พร้อมกัน
  • Permission module ใหม่ — เพิ่มในระบบ permission matrix ที่มีอยู่แล้ว (/admin/permissions)
